# AT Digital Onboarding Passport (Allied-Tek)

ระบบบริหารจัดการพนักงานใหม่ตั้งแต่ก่อนเริ่มงานจนครบกำหนดทดลองงาน — หน้าเว็บเดียว ไม่มี backend ของตัวเอง เก็บข้อมูลทั้งหมดไว้ใน **Google Sheet ของคุณเอง** ผ่าน **Google Apps Script** (เหมือนสถาปัตยกรรมของโปรเจกต์ HROD เดิม)

```
[GitHub Pages: index.html]  --fetch-->  [Google Apps Script Web App]  --read/write-->  [Google Sheet ของคุณ]
```

ข้อมูลพนักงาน, Journey Template, Onboarding Checklist, KPI, แบบสะท้อน 2 ทาง ฯลฯ ทั้งหมดอยู่ใน Google Sheet เดียว หัวตารางเป็นภาษาไทย จัดรูปแบบสีสันให้อัตโนมัติ — ไม่มีสำเนาเก็บที่อื่น

## การตั้งค่าครั้งแรก (ทำครั้งเดียว)

### 1. สร้าง Google Sheet + Apps Script

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่ออะไรก็ได้ เช่น "AT Onboarding Passport DB"
2. เมนู **Extensions (ส่วนขยาย) → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทิ้งทั้งหมด แล้ววางโค้ดทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ในโปรเจกต์นี้ลงไปแทน
4. กด **Save** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)
5. ที่ dropdown เลือกฟังก์ชันด้านบน เลือก **setupSheets** แล้วกด **Run** (▶️)
   - ครั้งแรกจะขอ **Authorize access** → กด Authorize → เลือกบัญชี Google ของคุณ → จะมีหน้าเตือน "Google hasn't verified this app" ให้กด **Advanced → Go to (ชื่อโปรเจกต์) (unsafe)** แล้ว Allow (ปลอดภัยเพราะเป็นโค้ดของคุณเองที่รันในบัญชีคุณเอง)
   - หลังรันเสร็จ กลับไปเปิด Google Sheet จะเห็นชีตทั้งหมดถูกสร้างพร้อมหัวตารางภาษาไทย สีแดงตามแบรนด์ และ Template เริ่มต้น 2 ชุด

### 2. Deploy เป็น Web App

1. มุมขวาบน กด **Deploy → New deployment**
2. ที่ "Select type" กดไอคอนเฟือง เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (บัญชีของคุณ)
   - **Who has access:** **Anyone**
4. กด **Deploy** → **Authorize access** อีกครั้งถ้าขอ
5. จะได้ **Web app URL** หน้าตาประมาณ:
   ```
   https://script.google.com/macros/s/AKfycby.../exec
   ```
   **คัดลอก URL นี้เก็บไว้** — ต้องใช้ในขั้นตอนถัดไป

> ทุกครั้งที่แก้โค้ดใน `Code.gs` แล้วอยากให้มีผล ต้องกด **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version → Deploy** ใหม่

### 3. เปิดใช้งาน GitHub Pages

1. ไปที่ repo นี้บน GitHub → **Settings → Pages**
2. Source เลือก **Deploy from a branch** → Branch: **main** / Folder: **/(root)** → Save
3. รอสัก 1-2 นาที จะได้ลิงก์เว็บ เช่น `https://<username>.github.io/<repo>/`

### 4. เชื่อมเว็บเข้ากับ Apps Script

1. เปิดเว็บ AT Digital Onboarding Passport (ลิงก์จาก GitHub Pages)
2. หน้าแรกจะขอ **"เชื่อมต่อฐานข้อมูล"** — วาง **Web app URL** จากขั้นตอนที่ 2 ลงไป แล้วกด **บันทึกและเชื่อมต่อ**
3. ถ้าเชื่อมต่อสำเร็จ จะเข้าหน้า Login ได้ทันที

> URL นี้เก็บไว้ใน localStorage ของเบราว์เซอร์แต่ละเครื่อง — **ทุกคนที่จะใช้ระบบ (HR, หัวหน้างาน, พนักงาน) ต้องวาง URL เดียวกันนี้ ในเบราว์เซอร์ของตัวเองครั้งแรกที่เปิดใช้** (เพราะเป็น static site ไม่มี server เก็บ config กลาง)

### รหัสเข้าใช้งานเริ่มต้น

- HR Admin: `hr2026`
- หัวหน้างาน / พี่เลี้ยง: `lead2026`
- พนักงานใหม่: เลือกชื่อจากรายการ (ไม่ต้องใช้รหัสผ่าน) — HR ต้องเพิ่มพนักงานในระบบก่อน

แก้รหัสผ่านได้ที่หน้า **System Settings** หลัง login ด้วย HR Admin

## โครงสร้าง Google Sheet

| ชีต | เนื้อหา |
|---|---|
| **ตั้งค่าระบบ** | ชื่อระบบ / หน่วยงาน / รายชื่อบริษัท |
| **Template การ Onboarding** | Journey Template แยกตามแผนก/ตำแหน่ง พร้อมระยะเวลาทดลองงานเริ่มต้น |
| **พนักงาน** | ข้อมูลพนักงานแต่ละคน ความคืบหน้า วันครบกำหนด ผู้ติดต่อ |
| **Checklist Onboarding** | รายการ checklist ทุกเฟสของพนักงานทุกคน (อ่านอย่างเดียว — แก้ผ่านแอป) |
| **ตัวชี้วัด KPI ทดลองงาน** | ตาราง KPI ของพนักงานแต่ละคน (อ่านอย่างเดียว) |
| **แบบสะท้อน 2 ทาง** | คำตอบแบบสะท้อนทุกรอบ ทุกคำถาม (อ่านอย่างเดียว) |
| **ผู้ใช้งานระบบ** | รหัสผ่าน HR / หัวหน้างาน |

ชีต "พนักงาน" และ "Template การ Onboarding" มีคอลัมน์สุดท้ายเป็น JSON ทั้งก้อน — คือฐานข้อมูลจริงที่แอปใช้งาน ส่วนคอลัมน์อื่นๆ (รวมถึงชีต Checklist/KPI/แบบสะท้อน ทั้งชีต) เป็น "มุมมองสรุปภาษาไทย" ที่ระบบสร้าง/อัปเดตให้อัตโนมัติทุกครั้งที่บันทึกพนักงาน สำหรับเปิดดูหรือทำรายงานต่อโดยตรงใน Sheet — **แก้ไขข้อมูลพนักงานผ่านหน้าเว็บเท่านั้น** การแก้ในคอลัมน์สรุปหรือ JSON โดยตรงจะถูกเขียนทับเมื่อมีการบันทึกครั้งถัดไป

## ข้อจำกัดที่ควรรู้

- **ไม่ realtime แบบ 100%** — หน้าเว็บจะดึงข้อมูลใหม่ทุก ~4 วินาที
- **ไม่มีระบบ login/สิทธิ์จริงระดับ server** — ใครก็ตามที่มี Web app URL จะอ่าน/เขียนข้อมูลได้ทั้งหมด (รหัสผ่าน HR/หัวหน้างานเป็นแค่ด่านกันพลาดในแอป ไม่ใช่การยืนยันตัวตนระดับเซิร์ฟเวอร์) เหมาะกับทีมที่ไว้ใจกัน ไม่ควรแชร์ URL นี้แบบสาธารณะ
- **Google Apps Script มี quota** — บัญชี Google ฟรีมีโควตาการเรียกสคริปต์ต่อวันจำกัด (ปกติหลักพันครั้ง/วัน) เพียงพอสำหรับทีมขนาดเล็ก-กลาง

## โครงสร้างโปรเจกต์

```
index.html              หน้าเว็บทั้งหมด (HTML/CSS/JS ในไฟล์เดียว)
manifest.json / sw.js   ทำให้ติดตั้งเป็น PWA บนมือถือ/เดสก์ท็อปได้
assets/                 ไอคอนแอป
apps-script/Code.gs     โค้ด backend ที่ต้องเอาไปวางใน Google Apps Script (ดูขั้นตอนด้านบน)
```

## พัฒนาต่อ / แก้ไขหน้าเว็บ

แก้ไข `index.html` ได้โดยตรง (เป็น vanilla JS ไม่มี build step) แล้ว commit + push ขึ้น `main` — GitHub Pages จะอัปเดตเว็บให้อัตโนมัติภายในไม่กี่นาที
